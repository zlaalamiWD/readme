HD March release includes new features and updates to existing events:

### Updated Existing events to include new elements:

<Image align="center" width="0px" src="https://files.readme.io/48a6078-image.png" />

* RxShipped Event: Includes shipping date to reflect the date when the prescription was shipped from HD facility.
* RxIssue Event: Includes claimRejectCode and Claim Description to relay the claim adjudication rejection reason.

### Get Fill Request

* The Fill Request API (GET) allows clients to retrieve all status and event summary for submitted Fill Requests.

### Technology Upgrade

* Improved messaging for 500 service errors to include HD Internal error code and trace ID aiding production support
