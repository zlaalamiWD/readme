We have added documentation for the /v2/mailbox endpoint ([MailBox](https://docs.healthdyne.com/v2.0/docs/mail-box)). The MailBox API allows clients to get status events for RxTransfer and FillRequest event types. More event types will be added over time so subscribe to the RSS feed for updates.
