* eRx and Rx Transfer workflow definitions [Workflows](https://docs.healthdyne.com/v2.17/docs/workflows#rx--fulfillment-workflows)
* RxReceived status events for eRx [RxReceived](https://docs.healthdyne.com/v2.17/docs/mail-box#rxreceived)
* RxDiscontinued status event [RxDiscontinued](https://docs.healthdyne.com/v2.17/docs/mail-box#rxdiscontinued)
* Script API script query [GET Script](https://docs.healthdyne.com/v2.17/docs/mail-box#rxdiscontinued)
* Add insurance plans on Patient [Insurance](doc:insurance)
